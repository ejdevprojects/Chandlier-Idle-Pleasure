# Interactive Chandelier 🕯️
A physics-based, interactive chandelier simulation built with Python and Pygame. 

## Features
* Soft-body physics (Verlet Integration)
* Glowing, layered light effects
* Interactive "grazing" mechanics (push the strings with your cursor)
* Auto-scales to your monitor in full screen

## How to Run
1. Install Python (python.org)
2. Install the required library: `pip install -r requirements.txt`
3. Run the script: `python chandelier.py`

## Controls
* Move your mouse/touchpad to brush the strings.
* Press `ESC` to exit full screen.
